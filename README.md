# Skill Studio

A free desktop app for creating, testing, and refining agent skills.

This repository hosts official Skill Studio installers, release notes, and update information. Application development takes place in a separate private repository.

## Downloads

Get the latest installer from the [Releases page](https://github.com/skillfully-sh/skill-studio-releases/releases/latest):

- **Mac:** Apple Silicon, macOS 13 or later — download the `.dmg`.
- **Windows:** x64 PCs — download the `.exe`.

The current Mac download is ad-hoc signed and is not notarized. The Windows installer does not yet have a trusted publisher certificate. Your operating system may ask for approval during the first installation; see the release notes. Updater packages are separately signed and verified by Skill Studio.

## Updates

Updater-enabled builds can check for and download updates in the background. A downloaded update is installed the next time Skill Studio opens. You can also use **Settings → Updates → Restart to update** when your work is saved and no agent is running.

Existing builds without the updater need one manual upgrade. Updates preserve your skills, conversations, and preferences.

Update packages are signed and verified before installation. Operating-system signing is listed separately in each release's notes.

## Issues

Please include your Skill Studio version and operating system when reporting a problem. Remove private skill content, conversation history, credentials, and personal information from screenshots or logs before sharing them in a public issue.
